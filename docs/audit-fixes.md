## 配置和上线行为

使用外部推送脚本的部署必须补 `INGEST_SOURCE_IDS`（逗号分隔，如 `my-crawler`）。留空会返回 403；名单中的 ID 也必须属于启用的 external 信源。该名单约束当前唯一的 `INGEST_TOKEN`；没有新增多 token 管理功能。

登录限流按当前单 API 进程部署工作。每进程最多保留 50 次已接纳尝试，拒绝请求不增加 IP key；未来扩容为多 API 副本时，需把限流计数迁至共享存储。

更新部署需要执行增量迁移并重建容器，才能替换原生 SVG 库。旧的撤稿投影会在下一轮恢复任务对账；迁移恢复的文章和语言误判文章由现有扫描继续处理。采集周期仍为每天两次，模型/推送的生产开关未在本次修复中更改。
